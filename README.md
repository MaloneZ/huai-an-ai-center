# 淮安市人工智能集散中心 · 运营管理平台

面向展馆运营团队的一体化管理网站，覆盖 **企业招商拜访、AI 展品资产管理、运营数据分析、数据备份与导入导出** 全流程。

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | React 18 + Vite + Ant Design 5 + ECharts + React Router |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3，单文件，备份=复制文件） |
| 认证 | JWT + bcrypt 密码加密 |
| 文件存储 | 本地 `server/data/uploads/` 目录 |
| 导入导出 | SheetJS（xlsx）支持 Excel/CSV |

## 功能模块

1. **用户登录 / 账号管理** — JWT 认证，三级角色（超级管理员 / 运营专员 / 访客只读）
2. **首页看板** — 拜访企业数、AI 相关企业数、软/硬件展陈品数；续租/跟进预警；县区分布、AI 技术标签 TOP8 图表
3. **企业拜访** — 顶部汇总栏 + 11 字段列表 + 多条件筛选 + 详情页（完整信息、图片上传、拜访记录时间线）
4. **展品管理** — 硬件/软件分类、展陈/资产/消费品/其他四分类、租赁/购买金额/租金/到期日/续租预警、状态灯
5. **运营分析** — 拜访转化漏斗、展品结构、技术标签分布
6. **数据管理** — 一键备份（zip 打包数据库+图片）、恢复、企业/展品 Excel 导入导出、模板下载
7. **系统设置** — 预警阈值、AI 标签字典管理

## 快速启动

### 环境要求
- Node.js ≥ 18（开发环境已用 v22 验证）

### 1. 启动后端

```bash
cd server
npm install
npm start
```

后端默认运行在 `http://localhost:3001`，首次启动会自动创建数据库并初始化默认账号。

### 2. 启动前端（开发模式）

```bash
cd client
npm install
npm run dev
```

前端运行在 `http://localhost:5173`，已配置代理转发 `/api` 和 `/uploads` 到后端。

### 3. 生产部署（可选）

```bash
cd client
npm run build      # 生成 client/dist

cd ../server
npm start          # 后端会自动托管 client/dist 静态文件
```

构建后访问 `http://localhost:3001` 即可。

## 数据目录结构

```
server/data/
├── center.db          # SQLite 数据库（核心数据）
├── uploads/           # 上传的图片
└── backups/           # 备份文件（zip）
```

## 数据备份与恢复

- **备份**：在「数据管理」页点击「立即备份」，系统将 `center.db` + `uploads/` 打包为 zip 存入 `backups/`。
- **恢复**：在备份列表点「恢复」，系统会**先自动备份当前数据**再还原，避免误操作。
- **手动备份**：也可直接复制 `server/data/` 整个目录。

## 导入导出

- **导出**：企业列表、展品清单一键导出 Excel。
- **导入**：支持中文表头模板批量导入，模板可在「数据管理」页下载。
- 企业表头：县区、企业名称、主营范围、名单来源、是否已拜访、地址、联系人、联系方式、拜访情况、是否AI相关、AI标签
- 展品表头：展品名称、产品类型、分类、获取方式、购买金额、租金、租赁到期、预警天数、AI标签、应用场景

## 开发说明

### 开发环境

- Node.js ≥ 18（推荐 v20/v22）
- npm ≥ 9
- 无需额外数据库，SQLite 由后端自动初始化

### 开发流程

```bash
# 1. 安装后端依赖
cd server && npm install

# 2. 安装前端依赖
cd ../client && npm install

# 3. 启动后端（端口 3001）
cd ../server && npm start

# 4. 另开终端启动前端（端口 5173，已配置代理）
cd client && npm run dev
```

开发模式下前后端分离运行，前端 Vite 已配置 `/api` 与 `/uploads` 代理到后端 3001 端口。

### 代码约定

- **前端**：React 函数组件 + Hooks，页面位于 `client/src/pages/`，路由集中在 `App.jsx`
- **后端**：按资源拆分路由（`routes/`），数据库操作集中在 `db.js`，认证逻辑在 `auth.js`
- **数据流**：前端 `api.js` 统一封装 axios，自动附加 JWT token，统一处理 401 跳转
- **API 规范**：统一返回 `{ success, message, ...data }` 结构

### 数据库说明

数据库由 `server/src/db.js` 在首次启动时自动建表并初始化默认账号与 AI 标签字典。如需重置，删除 `server/data/center.db` 后重启即可。

### 常用命令

| 命令 | 说明 |
|---|---|
| `cd client && npm run dev` | 启动前端开发服务器 |
| `cd client && npm run build` | 构建前端生产版 |
| `cd server && npm start` | 启动后端（生产模式会自动托管前端） |
